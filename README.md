# 番茄花园

番茄花园是一款把专注时间变成花园收获的网页应用。每完成一次 25 分钟专注，植物就长大一点。养成后，把它种进自己的花园。

## 怎么玩

1. 打开花园，点击「开始专注」。计时结束后，点击「确认」记录这次专注。
2. 第一种植物需要 3 次专注，第二种需要 4 次，从第三种起每种需要 5 次。
3. 植物养成后点「种进花园」，果蔬成熟后点「收获」，小动物出现后点「记录来访」。

小雏菊、矢车菊、金盏花依次出现，后续品种从尚未收集的条目中随机抽取。「我的花园」会显示植物种类和动物数量。使用管理员发来的专属链接，可以同步进度并查看好友排行榜。

## 本地体验

直接用浏览器打开 `index.html` 即可单人体验，进度保存在当前浏览器。想快速试玩，可以在地址末尾加上 `?mode=test`，每轮缩短为 5 秒，测试进度单独保存。
